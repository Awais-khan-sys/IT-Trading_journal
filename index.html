Voice Agent

Voice commands require Chrome or Edge browser. The mic button in the topbar activates voice recognition.
"dashboard / trades / analytics" Navigate
"add trade" Open form
"my balance" Read balance aloud
"win rate" Read win rate
"today's pnl" Read today P&L
"how many trades" Trade count
"dark mode / light mode" Switch theme
"export" Download CSV
